# NumPy Guide — Data, Given Shape

An illustrated guide to NumPy for people learning Python for data analysis.

**Published at:** https://tidyweb.github.io/numpy_guide/

## What it covers

- What NumPy is actually for — turning loose, messy data into one structured object
- Boxes inside boxes, and sheets bound into a book: the models the rest of the guide uses
- Why an array is not a list, and what that trade buys you
- Reading a shape, and reshaping without moving anything
- Indexing and slicing, from the front and from the back
- Filtering with masks, and why one line replaces ten
- Combining arrays laid over each other: broadcasting, `np.where`, and stacking
- What an axis is, and why it is not the x and y you learned at school
- Logarithms, distributions, mean against median, and `nan`
- A full cheat sheet, including a symptom-to-cause table

Eleven inline SVG figures. Six historical panels covering Hollerith's punched cards,
Iverson's notation, the Fortran ordering argument, the Numeric/numarray split,
Napier's logarithms, and IEEE 754 — each one included because it explains something
you will actually meet in the syntax.
